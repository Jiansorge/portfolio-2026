Joining Palms ↗

formerly Prayer Earth · pray with the whole world on a live 3D Earth that glows as people pray. Revolutionary in its simplicity: one shared space for every tradition, no accounts, no personal data, only a coarse 1° cell ever shared.

  • Holistic optimization: offline-ready PWA, Vite + code splitting, service worker caching, 60fps Three.js Earth with shader aura; Lighthouse minded, <150KB initial, 12 languages + RTL
  • Secure, accessible, and trustworthy: strict CSP without unsafe inline, XSS safe by construction, coarse location only and IPs never stored; semantic HTML, keyboard and screen reader support, high contrast
  • Reliable and inclusive by design: 145 prayers across 15 traditions, all public domain or original, wholesome, never shame or sin focused, respectful of Indigenous and living traditions; built to be maintainable and cost efficient

sync-engine ↗

The real time layer behind Joining Palms. An app agnostic presence, broadcast, and durable totals engine on Cloudflare Workers + Durable Objects · innovative edge architecture built to cost ~$0 per month, survive redeploys, and scale via sharding.

  • Performant and durable: WebSocket presence, live feed capped at 40 and coalesced, SQLite backed totals, debounced writes, sharding via ?cell= + Coordinator aggregation for global totals
  • Secure and reliable by design: origin allow list, per connection rate budget, SHA-256 hashed upgrade throttle, no outbound calls from WS input, 64KB message cap and strict field caps, always on and fault tolerant
  • Tested and portable: 53 Vitest tests including restart survival and protocol drift test that keeps the two protocol.js copies byte identical; any app can reuse the tiny engine.js interface
